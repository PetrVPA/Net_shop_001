# Учебный проект

## Описание:
Учебный проект электронного магазина, для реализации ООП. В настоящий момент реализовано создание двух классов Product и
Category. Также отработана утилита подгрузки информации о товаре с json файла и функция формирования на основе принятых
данных объектов класса. Ссылка на репозиторий: https://github.com/PetrVPA/Net_shop_001.git
В модуле utils.py реализована возможность формирования категорий и товаров из json файла. Для класса Category реализован
магический метод __str__ отображающий наименование и остаток товаров в категории.Так же реализована защита от 
добавления в категорию товаров не относящихся к классу Product и его дочерним классам. Реализован геттер отображающий 
полную информацию о объекте класса Category. В модуле product.py реализованы классы: абстрактный класс BaseProduct,
Product и дочерние классы Smartphone и LawnGrass. Для дочерних классов реализован магический метод __add__ складывать 
объекты своего класса и отображать общее количество и стоимость. В родительском классе, реализованы аналогичные дочерним
классам магические функции __add__ и __str__. Реализован класс метод new_product для создания нового продукта. Геттер
для отображения приватного атрибута price и сеттер для корректировки стоимости, с защитой от введения нулевого 
или отрицательного значения стоимости. Для родительского класса Product реализован миксин класс ProductMixin для
отображения класса товара, описания, его стоимости и количества.
